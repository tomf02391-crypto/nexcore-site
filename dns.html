域名管理后台

基于 DNSHE v2.0 API 的域名管理面板（管理功能页，已屏蔽搜索引擎索引）。输入并保存 API 密钥后，可查看域名列表、管理解析记录、查询配额与 WHOIS 信息。

⚠
安全提示：API 密钥等同于账户访问凭证。本页面不预填任何密钥，密钥仅保存在本机浏览器的 localStorage 中，请勿在公共电脑上保存；切勿将密钥提交到代码仓库或在公开环境部署本页面。如密钥泄露，请及时在 DNSHE 控制台重置。
