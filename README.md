# 星枢科技 XINGSHU TECH 官网 V3

## 本版内容
- 深空星轨首页与原创 SVG 品牌标识
- 产品矩阵、生态理念、品牌释义、社区入口完整页面
- PC / 平板 / 手机响应式布局
- 移动端导航、滚动导航状态、进入视口动效、轻量视差
- SEO 元信息、Open Graph 分享图、robots.txt、sitemap.xml
- 键盘可访问性、减少动态效果偏好支持
- 纯静态 HTML/CSS/JS，无构建依赖

## 本地预览
直接打开 `index.html`，或在目录中运行静态服务器：
`python -m http.server 8080`

## 部署
将此目录中的全部文件上传至静态网站根目录。确认 `index.html` 位于根目录，`assets/`、`styles.css`、`script.js` 同级。
域名规划：`xingshu.de5.net`
